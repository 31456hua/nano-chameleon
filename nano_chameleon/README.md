# 纳米变色龙源码

安装、启动和测试请从[仓库首页](../README.md)开始；详细操作见[复现说明](../docs/REPRODUCE.md)。

本目录包含物理计算、MCP 服务、本机演示台、六个测试模块，以及历史执行记录与报告。历史 AGH 技术记录保留在 `AGH_RUNBOOK.md`、`AGH_SCHEDULE.md` 等文档中，其中的日期、路径、端口及软件版本指当时环境，换电脑时需要调整。

手动仿真执行数值计算，历史回放展示已完成的 Agnes 任务。当前模型使用均匀球体与恒定 n/k，结果是仿真候选，尚无真实材料实验。组件许可和 AI 辅助范围见[来源说明](../docs/SOURCES.md)。
