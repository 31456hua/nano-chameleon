## 有界调度

从本目录执行，连接已启动且已配置模型的本机 daemon：

```text
python agh_dispatch.py benchmarks/20261010T151242Z_161152a2/agh_tasks_public.json --limit 4
python benchmark.py summarize 20261010T151242Z_161152a2 --agh-evidence benchmarks/20261010T151242Z_161152a2/agh_evidence_summary.json
```

完成的任务会保留，不重新消耗模型调用。`--retry-incomplete` 只允许重试尚未封存的任务，先归档失败证据。`--finish-sealed-incomplete` 只在已封存且有原会话证据的任务上恢复报告收尾，不允许搜索、试算或再次揭盲。

每条任务一次搜索，最多 15 代，固定种子 7；手动试算最多 12 次、最终验证一次、报告导出最多两次。SciPy 局部精修会产生额外候选评估。任务串行执行；默认超时 600 秒，支持 30-900 秒。启动阶段有独立期限，官方 SDK 组件缺失时明确拒绝启动。调度器仅关闭自己的 SDK 连接或取消自己的未完成会话，不停止用户 daemon，也不修改审批模式。

调度器需要 AGH 官方源码及其已安装依赖，当前位于项目 `work/agh-src/agnes-harness-main`。移机时通过 `--sdk-root` 指定已准备好的官方源码根目录，并按官方指南构建原生组件；Python 依赖文件不能安装 AGH/Node 运行时。已封存任务不要移入新的评测会话重新拟合。

## 启动故障处理

原工作台曾因凭据目录保护状态不符合 AGH 检查而无法启动。诊断只检查 ACL，不读取凭据内容。经获批移除了 AGH 主目录给测试账号的额外读取权限，并用官方函数保护旧备份，所有者、密钥内容和备份均保留；官方检查确认 8 项存储条目的权限合格。

本工具运行环境可能再次授予测试账号主目录读取权限，因此该问题可能复现。调度器不会自动修改凭据权限。遇到此错误，应在用户自己的 Windows 会话中使用 AGH 官方凭据诊断和保护方案；不要关闭检查、放宽 ACL、切换宽松审批或把密钥写进脚本。若运行环境需要修复，必须单独获得授权，不能把一次恢复视为永久解决。
