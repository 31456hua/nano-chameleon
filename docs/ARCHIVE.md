# 公开副本与历史归档

本公开版于 2026-10-21 从本地补交材料整理，源码仓库为 [31456hua/nano-chameleon](https://github.com/31456hua/nano-chameleon)。保留数值引擎、前端、测试、四条主要轨迹、完整结果、失败快照、基线、合成验证设定和第三方许可。源码与归档 JSON / HTML 按原文件复制；README 等入口文档为公开使用重写。

未收入报名表、联系方式、成员待签署声明、剪辑与 PPT 临时工程、本地 Python 缓存、视频文件及原补交包的全包校验清单。原目录保留不变。演示视频只在首页提供团队原材料记载的 B 站链接，本轮未完整复验在线播放。

`evidence/` 中带 `20261011` 的记录反映历史环境。`公开副本测试_20261021.txt` 记录本轮对准备版执行已有测试的实际结果。历史 AGH 文档中的“尚未制作视频”等文字只对应当时阶段。

`AGH_trace/` 内四份主要轨迹与 `nano_chameleon/benchmarks/20261010T151242Z_161152a2/` 内同名文件保留一致。轨迹中的本机会话 ID、回环地址与历史文件路径用于溯源，不提供远程访问权限。

`offline_validation/.../suite_private.json` 的 private 指实验揭盲前的访问范围，文件是已经封存的合成参数，不是个人隐私或模型密钥。公开后不宜用相同答案设计新的盲测。

`SHA256SUMS.txt` 为此公开副本另行生成，覆盖清单自身以外的全部准备文件。不要拿它与原补交包的全包清单混用。
