# 项目说明

纳米变色龙把目标光谱到颗粒参数的逆设计组织为可运行、可检查的流程。Agnes 通过 AGH 调用五个 MCP 工具：检查目标、试算候选、约束搜索、留出验证和报告导出。MiePython 负责球体散射计算，SciPy 负责数值优化。

## 物理与数据设定

- 均匀、单分散球形颗粒；扩展评测介质折射率为 1。
- 粒径 50–500 nm；n 为 1.05–2.8，k 为 0–0.35；采用 n-i·k 吸收约定。
- n/k 在波段内保持恒定。数据由程序合成，不含第三方实测光谱。
- CSV 使用 `wavelength_nm,qsca` 两列，15–400 个不同的正波长；Qsca 有限且非负。

## 留出验证

扩展评测在 390–810 nm 的 43 个波长中使用 35 个训练点和 8 个内部留出点。先仅按训练误差选定并锁定参数，再公开留出目标。揭盲后禁止继续拟合该实验。

留出 NRMSE = 留出 RMSE / 训练目标 Qsca 的均方根，分母下限为 1e-8。科学门槛在拟合前声明。它衡量原波段内的留出误差，尚未验证波段外预测或真实材料精度。

完整封存目标随归档公开，属于合成实验设定。新实验应另行准备数据，避免将已经公开的留出答案用于拟合。这里的流程隔离并非第三方独立保管的盲测。
